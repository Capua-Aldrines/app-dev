# Jackie Chan's Movies

> "I've never wanted to be the next Bruce Lee. I just wanted to be the first Jackie Chan." — Jackie Chan

---

## Overview

Jackie Chan's action-comedy films combine traditional martial arts with slapstick physical humor and intricate stunt work.

### Key Details

- **Genre**: Action / Martial Arts / Comedy
- **Style**: Practical stunts, prop-based fighting, and outtakes during credits
- **Notable Films**: *Police Story*, *Drunken Master*, *Rumble in the Bronx*, and *Rush Hour*
